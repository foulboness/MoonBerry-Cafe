# MoonBerry Café ☕

A modern and responsive recipe website built to showcase, atmosphere. Designed with a clean UI, smooth navigation, and mobile-friendly.

---

## Features

* Responsive design for mobile, tablet, and desktop
* Hello Kitty themed UI
* Smooth and clean navigation
* Beautiful hero section and branding
* Fast deployment using Netlify
* Optimized layout and styling

---

## Built With

* HTML5
* CSS3
* JavaScript
* Netlify Deployment
